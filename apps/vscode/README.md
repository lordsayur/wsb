# Waktu Sembahyang Brunei — VS Code

Prayer times for Brunei in the editor status bar, plus a sidebar view with all
eight entries. The bar shows the current entry; the next one and the duration
to it live in the tooltip. Opt-in notifications fire 15 minutes before and at
each prayer while VS Code is running, and the extension asks once on first
install.

Open the view from the activity-bar icon, the status bar item, or the command
palette (`Waktu Sembahyang: Open times view`). The view links to the web app and
credits the data source. Settings live under `wsb.*` in the editor
configuration: status bar on/off, notifications on/off, language, time format
and district.

The `.vsix` ships from
[GitHub releases](https://github.com/lordsayur/wsb/releases/latest).
