# Waktu Sembahyang Brunei — VS Code

Prayer times for Brunei in the editor status bar, plus a times panel with all
eight entries. A thin shell over `@wsb/core`; offline first, Supabase-backed.

Open the panel from the status bar item or the command palette
(`Waktu Sembahyang: Open times panel`). Settings live under `wsb.*` in the
editor configuration: status bar on/off, language, time format and district.

The `.vsix` ships from
[GitHub releases](https://github.com/lordsayur/wsb/releases/latest).
